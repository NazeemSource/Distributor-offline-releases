# Distributor Offline — Downloads

This repository contains public Windows builds and installation instructions only.

[Download the Windows application](https://github.com/NazeemSource/Distributor-offline-releases/releases/download/v1.0.0/DistributorOffline-win-x64.zip)

## Install

1. Download and extract the entire ZIP.
2. Run DistributorApp.exe.
3. On a fresh installation, select Admin, choose Administrator, and enter 1234.

Default username: admin. Existing accounts and changed passwords are preserved.
The .NET runtime is included; business operations work offline.

See the release's README.txt for setup and backup instructions.
SHA256.txt contains the Windows package checksum.

Application source code is maintained separately in a private repository.
